# Tourism & Hospitality Management Writing Skill

An AI skill for drafting and polishing academic papers in tourism and hospitality management — targeting journals such as *Tourism Management*, *Annals of Tourism Research*, *Journal of Travel Research (JTR)*, and *International Journal of Hospitality Management (IJHM)*.

## Installation

```bash
git clone https://github.com/liyuanbo1024/tourism-management-writing.git
```

Then copy the skill file into your AI coding tool:

```bash
# OpenCode / Claude Code
cp tourism-management-writing/SKILL.md ~/.config/opencode/skills/tourism-management-writing/

# Codex
cp tourism-management-writing/SKILL.md ~/.config/codex/skills/tourism-management-writing/

# Cursor
cp tourism-management-writing/SKILL.md ~/.cursor/skills/tourism-management-writing/

# Windsurf
cp tourism-management-writing/SKILL.md ~/.windsurf/skills/tourism-management-writing/
```

## Quick Start

Trigger the skill by mentioning any of the following in conversation:

```
Write an introduction for a Tourism Management paper on sustainable destination
competitiveness.

Polish the literature review section — Annals of Tourism Research style.

Generate a structured abstract for IJHM on hotel revenue management post-COVID.

Draft a methodology section for JTR using a mixed-methods approach with PLS-SEM.
```

The skill provides:

- Section drafting (IMRaD) with journal-specific tone and conventions
- Literature review synthesis and gap identification
- Methodology justification (PLS-SEM, fsQCA, multi-level modeling, etc.)
- Polishing for grammar, clarity, and journal style compliance
